### All deleted files recoverable from Git history:

**To recover a file:**
```bash
# List commits where file existed
git log --all --full-history -- "FILENAME.md"

# View file content from specific commit
git show <commit-hash>:FILENAME.md

# Restore file from history
git checkout <commit-hash> -- FILENAME.md
```

**Example:**
```bash
# Recover PRODUCTION_DEPLOYMENT_GUIDE.md
git log --all -- "PRODUCTION_DEPLOYMENT_GUIDE.md"
git show 48d317c:PRODUCTION_DEPLOYMENT_GUIDE.md > recovered.md
```
